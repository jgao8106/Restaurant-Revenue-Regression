# Restaurant Revenue Regression

This project uses R and multiple linear regression to predict monthly restaurant revenue using a dataset of 300 restaurants.

## Project Overview

The goal of this project was to build and evaluate regression models that estimate restaurant monthly revenue based on operational and business characteristics.

## Methods

- Performed an 80/20 train-test split
- Built and compared multiple linear regression models
- Created polynomial and interaction terms
- Evaluated multicollinearity among predictors
- Compared model performance using MSE and RMSE

## Results

- Compared three regression models
- Final model achieved a test RMSE of approximately $5,510
- Improved prediction error by approximately 54% compared with the initial model
